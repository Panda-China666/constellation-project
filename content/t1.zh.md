## 课程简介

以概率、优化、信息论与随机分析为基础，建立研究机器学习模型所需的数学工具。课程关注定理假设、证明方法及其在有限样本与有限规模模型中的适用边界。

**课程长度**：14 周 · 研究生课程  
**先修基础**：测度论概率、线性代数、实分析与基础优化。

## 周次安排

| 周次 | 研究内容 |
| --- | --- |
| 1–2 | 测度论概率、条件期望、集中不等式、随机过程 |
| 3–4 | 高维概率、随机矩阵理论、谱分析、自由概率基础 |
| 5–6 | 凸分析、非凸优化、变分分析、随机优化与隐式正则化 |
| 7–8 | 信息论、PAC-Bayes、算法稳定性、泛化界、信息瓶颈 |
| 9–10 | 贝叶斯推断、变分推断、统计物理、自由能与 Gibbs 分布 |
| 11–12 | 最优传输、Wasserstein 几何、连续性方程、梯度流 |
| 13–14 | 随机微分方程、Fokker–Planck 方程、随机控制与扩散过程 |

## 学习目标

- 掌握课程涉及的核心数学对象、算法与研究方法。
- 识别理论假设，分析方法的适用范围与失效条件。
- 将文献阅读、理论分析与可复现实验结合。

## 研究任务

证明一个关键结论，构造检验其假设的反例，并通过数值实验比较理论预测与有限规模行为。

## 成果要求

提交研究报告与必要的代码或证明。报告需说明问题定义、相关工作、方法、证据及局限性。
