## Overview

Study how intelligent systems represent problems, accumulate knowledge, allocate computation and perform verifiable reasoning. Connect computational complexity, program induction, search, planning, memory and mechanistic interpretability.

**Duration**: 14 weeks · Graduate level  
**Prerequisites**: Algorithms, theory of computation, probabilistic inference and deep learning.

## Weekly schedule

| Weeks | Research topics |
| --- | --- |
| 1–2 | Computational complexity, program induction, algorithm learning, compositional generalization |
| 3–4 | Neural-symbolic reasoning, program synthesis, formal verification, proof search |
| 5–6 | Reasoning as search, inference-time computation, metareasoning |
| 7–8 | Learning to plan: hierarchical planning, belief-state planning, long-horizon dependencies |
| 9–10 | Memory as learning: learnable memory, state compression, continual learning, knowledge updates |
| 11 | Active information acquisition, Bayesian experimental design, active perception |
| 12 | Multi-agent intelligence: games, coordination, communication, decentralized decisions |
| 13 | Mechanistic interpretability, causal interventions, reasoning faithfulness |
| 14 | Foundational research proposal and defense |

## Learning objectives

- Understand the central mathematical objects, algorithms and research methods.
- Identify assumptions, applicability limits and failure conditions.
- Connect literature review, theoretical analysis and reproducible experiments.

## Research assignment

Pose a foundational question about reasoning computation, learnable memory or reasoning faithfulness. Define testable assumptions, evaluation methods and failure conditions.

## Deliverables

Submit a research report with the necessary code or proofs. State the problem, related work, method, evidence and limitations.
