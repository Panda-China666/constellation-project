## Overview

Study efficient kernels, compiler optimization and hardware–algorithm co-design from GPU microarchitecture, memory hierarchy and performance bounds. Use performance models to explain gains and limitations across hardware, problem sizes and precision formats.

**Duration**: 14 weeks · Graduate level  
**Prerequisites**: Computer architecture, parallel algorithms, C/C++ and deep learning.

## Weekly schedule

| Weeks | Research topics |
| --- | --- |
| 1–2 | GPU microarchitecture, memory hierarchy, roofline model; FLOP counts, memory traffic, bandwidth lower bounds |
| 3–4 | CUDA, Triton, CuTe, tile programming; matrix multiplication, reductions, fused kernels |
| 5–6 | FlashAttention, online softmax; I/O complexity, tiling, asynchronous execution |
| 7–8 | GPU compilers, MLIR, XLA, kernel fusion; IR transformations, autotuning, code generation |
| 9–10 | Mixed precision, FP8, FP4, numerical stability; quantization and accumulation error |
| 11–12 | Sparse computation, MoE kernels, irregular workloads; load balancing, sparse access, scheduling |
| 13–14 | Hardware–algorithm co-design; kernel or scheduling optimization and research defense |

## Learning objectives

- Understand the central mathematical objects, algorithms and research methods.
- Identify assumptions, applicability limits and failure conditions.
- Connect literature review, theoretical analysis and reproducible experiments.

## Research assignment

Optimize a kernel or scheduling bottleneck. Provide correctness checks, a performance model and baseline comparisons on identical hardware and precision.

## Deliverables

Submit a research report with the necessary code or proofs. State the problem, related work, method, evidence and limitations.
